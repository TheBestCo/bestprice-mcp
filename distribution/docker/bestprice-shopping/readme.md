# BestPrice Shopping

Read-only shopping decisions, product search, live offers, delivered totals, and price history for Greece. No BestPrice account or API key.

- Name: BestPrice Shopping (`bestprice-shopping`)
- Endpoint: https://mcp.bestprice.gr/mcp
- Authentication: none
- Transport: Streamable HTTP
- Server version: 1.8.5
- License: Apache-2.0
- Tools: `get_shopping_decision`, `search_products`, `compare_offers`, `get_price_history`
- Icon: https://raw.githubusercontent.com/TheBestCo/bestprice-mcp/main/assets/bestprice-mcp-logo-1024.png
- Documentation: https://www.bestprice.gr/mcp
- Privacy: https://www.bestprice.gr/policies/privacy
- Support: https://www.bestprice.gr/contact
- Source: https://github.com/TheBestCo/bestprice-mcp

The four shopping tools do not place orders, take payment, create alerts, or expose direct merchant links.
The icon is the square 1024×1024 PNG, the same URL as docker/mcp-registry#5228.
